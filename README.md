# Skelbimų medžioklė

Kas valandą tikrina Skelbiu.lt paieškas (`paieskos.json`), atrenka naujus skelbimus pagal raktažodžius ir kainas,
saugo istoriją `data/skelbimai.json`. Sistema niekada nieko neperka, nerašo pardavėjams ir nededa skelbimų.

Proxy duomenys tik GitHub Secrets: `LUMINOR_PROXY_SERVER`, `LUMINOR_PROXY_USERNAME`, `LUMINOR_PROXY_PASSWORD`.
Repo viešas: čia nelaikomi pirkimai, pardavimai, pelnas ar asmeniniai duomenys.
