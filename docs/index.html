Prisijungimas įrašymui (vieną kartą)

Žurnalas saugomas šiame repo faile docs/sandoriai.json. Kad svetainė galėtų jį įrašyti, reikia GitHub rakto, kuris leidžia keisti tik šį repo. Raktas lieka tik šioje naršyklėje.

  1. Atsidaryk naujo rakto kūrimą.
  2. Pavadinimas: „skelbimai-zurnalas“, galiojimas: 1 metai.
  3. Repository access: „Only select repositories“ → skelbimu-medziokle.
  4. Permissions → Repository → Contents: „Read and write“. Spausk „Generate token“ ir nukopijuok.
